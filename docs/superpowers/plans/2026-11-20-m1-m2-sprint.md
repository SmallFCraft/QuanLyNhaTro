# Sprint M1+M2 — QuanLyNhaTro Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dựng khung dự án chạy được ổn định: TCP server + đăng nhập PBKDF2 6 vai trò + RBAC (M1) và CRUD khu/phòng/người thuê theo scope khu (M2).

**Architecture:** 4 project .NET 8 — `QuanLyTro` (WinForms host WebView2), `QuanLyTro.Server` (console TCP 8888), `QuanLyTro.Shared` (packet/models), `QuanLyTro.Tests` (MSTest + MySQL `quanly_nhatro_test`). JSON-per-line protocol với requestId correlation; RBAC deny-by-default kiểm tra trước service; scope khu lấy từ session.

**Tech Stack:** .NET 8, MySqlConnector 2.4.0, MSTest 3.7.0, WebView2 1.0.2903.40, MySQL 8.0 (Laragon).

**Spec:** `docs/superpowers/specs/2026-11-20-m1-m2-sprint-design.md`

## Global Constraints

- Target `net8.0`; MySQL Laragon user `root` không password (dev); DB test chỉ `quanly_nhatro_test`, connection string fail nếu trỏ DB khác.
- Entity/tên role không dấu: `ChuTro, QuanLy, LeTan, NhanVien, KhachThue, CongAn`; bảng/cột snake_case không dấu.
- Mọi packet bắt buộc `requestId`; frame giới hạn 262144 bytes; mọi query parameterized.
- Commit message tiếng Việt không dấu, không Co-Authored-By / attribution.
- Schema idempotent — chạy lại không mất dữ liệu.

## Review Focus

- Packet dính/tràn: 2 JSON liền 1 lần đọc và JSON > 256KB — phải parse đúng gói đầu và trả lỗi rồi đóng kết nối, không sập server (test Task 4).
- Lockout biên: lần sai thứ 5 khóa đúng 1 phút; thành công reset đếm (test Task 5).
- Giả mạo scope: packet QuanLy khu A gửi khuTroId=B — phải trả lỗi không lộ bản ghi tồn tại (test Task 8).
- Đua sức chứa: 2 request gán cùng phòng cuối cùng — đúng 1 thắng (test Task 9).
- Trùng CCCD đăng ký đồng thời: 1 thành công, transaction rollback sạch không để rác tài khoản không hồ sơ (test Task 9).
